# Davranış kuralları / Code of conduct

Bu proje [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) davranış
kurallarını benimser. Issue, pull request, tartışma ve proje adına yapılan tüm iletişimde geçerlidir.

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to issues, pull requests, discussions and all communication on behalf of the project.

## Bildirim / Reporting

Kabul edilemez bir davranışı **matriksiq@matriksdata.com** adresine bildirebilirsiniz (konu: `matriks-pii conduct`).
Bildirimler gizli tutulur ve proje sorumlularınca incelenir.

Unacceptable behaviour can be reported to **matriksiq@matriksdata.com** (subject: `matriks-pii conduct`). Reports are
kept confidential and reviewed by the project maintainers.

## Ek kural / Additional rule

Issue, PR ve tartışmalarda **gerçek kişisel veri veya gerçek anahtar paylaşmayın**; yalnız sentetik örnek kullanın.
Gerçek kişisel veri içeren içerik proje sorumlularınca düzenlenir veya silinir.

Do **not** post real personal data or real credentials in issues, pull requests or discussions; use synthetic
examples only. Content containing real personal data will be edited or removed by the maintainers.
